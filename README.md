# FUTURE_ML_02 — Customer Support Ticket Classification

## Project Objective
This project classifies customer support tickets into categories using Natural Language Processing (NLP) and Machine Learning.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- VS Code

## Features
- Text preprocessing
- Ticket classification
- Machine learning model training
- Prediction of ticket categories
- Accuracy evaluation

## Sample Prediction
Input:
"Payment issue while placing order"

Predicted Category:
Billing
